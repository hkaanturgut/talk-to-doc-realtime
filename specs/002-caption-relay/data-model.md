# Data Model: Caption Relay

All state is in memory in the app process (`RelayQueue`). Nothing is persisted.

## RelayJob (server)

| Field       | Type                                     | Rules                                                      |
| ----------- | ---------------------------------------- | ---------------------------------------------------------- |
| `id`        | uuid v4                                  | opaque; generated by the app                               |
| `videoId`   | string                                   | `^[A-Za-z0-9_-]{11}$`; unique among in-flight jobs (dedupe) |
| `createdAt` | epoch ms                                 |                                                            |
| `expiresAt` | epoch ms                                 | `createdAt + 15 000`                                       |
| `state`     | `pending` → `leased` → (`done` \| `expired`) | removed from the queue on `done` or `expired`          |
| `waiters`   | promise resolvers                        | every viewer request waiting on this video                 |

State transitions:

- `pending → leased`: a relay poll takes the oldest pending job.
- `pending | leased → done`: a valid result arrives before `expiresAt`; all waiters resolve with it.
- `pending | leased → expired`: `expiresAt` passes; waiters reject with `TRANSIENT`; any later result
  for this id is rejected (`404`).

Invariants: at most 20 jobs in flight (more → enqueue refuses, provider fails fast); one job per
video id; a result is accepted at most once.

## RelayResult (relay → app)

Discriminated union, zod-validated (`RelayResultSchema` in `src/shared/schemas.ts`):

```ts
{ jobId: uuid, ok: true,  transcript: { text: string(1..MAX_TEXT_CHARS), language: string(≤ 35),
                                        autoGenerated: boolean, durationSeconds?: number ≥ 0,
                                        title?: string(≤ 300) } }
{ jobId: uuid, ok: false, kind: "NO_CAPTIONS" | "UNAVAILABLE" | "BLOCKED" | "TRANSIENT" }
```

Request body cap: 2 MB (checked from `content-length` and the read length).

## RelayPresence (server)

| Field        | Type     | Meaning                                         |
| ------------ | -------- | ----------------------------------------------- |
| `lastSeenAt` | epoch ms | end time of the most recent authenticated poll  |
| `polling`    | int      | authenticated polls currently waiting           |

`online = polling > 0 || now - lastSeenAt ≤ 30 000`.
